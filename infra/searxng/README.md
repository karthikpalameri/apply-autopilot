# 🔎 Local SearXNG — private web search for any coding agent

Project: **https://github.com/searxng/searxng**

A private, self-hosted metasearch engine bound to `http://127.0.0.1:8080`.
It gives every agent/script in this repo **free, private web search with a JSON API**
— no API keys, no tracking, no per-query cost.

## WHAT / WHY / HOW / WHEN

| | |
|---|---|
| **WHAT** | SearXNG queries many search engines and merges results into one JSON/HTML response. |
| **WHY** | Find **portal-only job roles** not on LinkedIn/ATS boards; verify companies/ATS domains; private + free. |
| **HOW** | Two Docker containers (`searxng-core` + `searxng-valkey`) started with `docker compose up -d`. |
| **WHEN** | During `hub.py install` (offered automatically), or before any FIND session that needs web search. |

## One-command setup (automatic)

```bash
python3 infra/searxng/setup.py
```

This writes `infra/searxng/.env` (with a random `SEARXNG_SECRET`) and
`infra/searxng/core-config/settings.yml` (enables the JSON API), then runs
`docker compose up -d` and **verifies the JSON API answers**.

## Manual setup

1. Start Docker Desktop / daemon.
2. From `infra/searxng`:
   ```sh
   cp .env.example .env          # edit SEARXNG_SECRET if you like
   docker compose up -d
   ```
3. Verify:
   ```sh
   curl -s 'http://127.0.0.1:8080/search?q=test&format=json' -H 'Accept: application/json'
   ```

## Everyday commands (from `infra/searxng`)

```sh
docker compose ps                # status
docker compose logs -f core      # logs
docker compose stop              # pause, keep data
docker compose start             # resume
docker compose down              # remove containers, keep volumes
docker compose pull && docker compose up -d   # update images
```

## Agent integration

- **pi:** `~/.pi/web-search.json` → `{ "provider": "all", "searxngBaseUrl": "http://127.0.0.1:8080" }`
  (generated by `python3 hub.py install` / `hub.py mcp-config`). Restart pi after writing.
- **Any script:** `curl 'http://127.0.0.1:8080/search?q=...&format=json'`
- **Skill:** `skills/searxng/SKILL.md` — "if you need searching, use this."

## Security

`core-config/settings.yml` is generated on first start and git-ignored (it holds the
instance secret). The instance is bound to `127.0.0.1` and must NOT be exposed to the
internet without authentication, rate limiting, and a reverse proxy.
