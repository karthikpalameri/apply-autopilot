# JOBVITE recipe (Nutanix)
## URL: jobs.jobvite.com/<co>/job/<id>/apply
## WIN: Nutanix Staff SDET ✅ | FLOW:

1. Data Consent screen: select `#jv-country-select` (index 1 = All Locations) →
   "Submit" (by clicking Submit you acknowledge privacy).
2. Form: fields by id (`jv-field-*`) — first/last/email/phone/company/school/grad(LinkedIn URL).
   selects: country=India, source=<closest — NO "LinkedIn" option; use "Web Search">, qual=Bachelor's.
   gender radio: click LABEL (input check fails outside viewport).
3. Resume: `input[type=file]` setInputFiles → shows filename.
4. Submit → `/applyConfirmation` "Application Sent!" = PROOF.
